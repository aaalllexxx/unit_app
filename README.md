# Портал IT-лаборатории UNIT — app.labunit.ru

Проекты, люди, направления (ИБ, разработка ПО, нейросети) и учёт времени.
Вход — только через UNIT ID (auth.labunit.ru, OpenID Connect + PKCE).

## Что внутри

- **Проекты** делятся на части (модули, сервисы, исследования). Каждая часть проходит этапы
  «Планирование → Реализация → Тестирование → Релиз»; у части есть процент готовности текущего
  этапа. Из этого считается готовность части и всего проекта (доли этапов: 15 / 50 / 25 / 10 %).
- **Задачи** — канбан по проекту, с привязкой к части и этапу, исполнителем, оценкой и сроком.
- **Люди** — направление, группа, грейд, должность, навыки, активность (дни с заходами, календарь).
- **Учёт времени** — часы по проектам и задачам по неделям.
- **Заказчики** видят только свои проекты: готовность, части и журнал «для заказчика».
- **Лендинг** — публичные проекты (флаг «Показывать на лендинге» и отдельные тексты для внешних).
- **Обзор руководителя** — загрузка людей, проекты в срок / с риском / просроченные, роли и доступы.
- **Письма** — о новой задаче, добавлении в проект, записях для заказчика.

Роли: руководитель лаборатории, руководитель направления, сотрудник, заказчик. Первый вошедший
и администраторы UNIT становятся руководителями лаборатории; остальные ждут подтверждения.

## Запуск

1. Зарегистрировать приложение в UNIT ID (админка UNIT ID → «Приложения»):
   адрес возврата `https://app.labunit.ru/auth/callback`, права `openid profile email`.
2. Положить рядом `.env`:
   ```
   LAB_CLIENT_ID=unit-…
   LAB_CLIENT_SECRET=…
   LAB_CONTACT=lab@labunit.ru
   ```
3. `docker compose up -d --build` — приложение слушает 127.0.0.1:5008, наружу — через nginx.

Локально: `LAB_DATA=./data LAB_SECURE=0 python -c "from app import app; app.run(port=5008)"`.
